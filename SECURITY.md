# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.3.x   | Yes       |
| < 0.3   | No        |

## Reporting a Vulnerability

If you discover a security issue, please open a private report via GitHub Security Advisories or email the repository owner.

Do not open public issues for exploitable vulnerabilities.

## Notes

- This project is not affiliated with RuStore or VK.
- The app downloads APK files from RuStore public endpoints and stores them in app-private storage.
- No credentials or RuStore account login is required or supported.
